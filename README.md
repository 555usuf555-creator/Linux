# monagent и проверка бэкапов

Скрипты из статей канала. Всё, что здесь лежит, **было собрано и проверено на
работающей ALT Linux 10.4** — с настоящими ошибками, настоящими выводами команд
и настоящими поломками, которые чинились по ходу.

Не пересказ документации. Это то, что реально работает.

---

## Что внутри

| Папка | Что это | Статья |
|---|---|---|
| `monagent/` | агент мониторинга на Python без зависимостей: HTTPS, `/metrics`, `/healthz`, изоляция systemd | «Агент мониторинга на 200 строк» |
| `backup/` | бэкап с ежедневными снапшотами и **проверкой восстановимости** | «Бэкап, из которого нельзя восстановиться» |
| `tools/` | пример проверочного скрипта, с которого начинался разбор | «Служба не запускается» |

---

## Быстрый старт

### Агент мониторинга

```bash
cd monagent
sudo ./install.sh
curl -sk https://127.0.0.1:8443/metrics
```

Слушает **только 127.0.0.1** — наружу не выставлено, это сделано намеренно.

### Бэкап с проверкой

```bash
cd backup
sudo ./install.sh
```

Скрипт установки **намеренно портит снапшот** и смотрит, поймает ли его
проверка. Если проверка проходит на испорченных данных — установщик об этом
скажет. Проверка, которая ничего не делает, хуже отсутствующей.

## Что эти проекты сделали не так и как это чинилось

Публикую поломки, потому что они полезнее идеальных скриптов.

| Что сломалось | Причина | Как исправлено |
|---|---|---|
| Агент падал 31 перезапуск | ключ `600` принадлежал root, а служба работает от `monagent` | `chgrp monagent` + `chmod 640` |
| Метрики обнулились | `ProcSubset=pid` закрыл `/proc`, а агент читает `/proc/stat` | директива убрана, изоляция ослаблена осознанно |
| `/nope` отдавал HTTP 200 | `startswith("/")` ловит любой путь | заменено на `path in ("/", "")` |
| Таймер не запускался | `systemctl enable` создаёт symlink, но **не стартует** таймер | добавлен `systemctl start` |
| Снапшоты били друг друга | `date` с точностью до секунды, два запуска давали одно имя | в имя добавлен `$$` |
| `du` показывал неправду | жёсткие ссылки от `--link-dest`, inode считается один раз | честный размер считается через иноды |

## Требования

- ALT Linux 10.4 / любой systemd-дистрибутив
- `python3` (проверено на 3.9)
- `openssl`
- `rsync` (только для `backup/`)
- root

На Debian/Ubuntu должен работать: пути в unit-файлах поправьте на свои,
`/opt` и `/usr/local/sbin` обычно те же.

---

## Безопасность

- Скрипты читали системные файлы и требуют root. Это нормально для установки,
  но означает: **не запускайте то, что не прочитали.**
- `monagent` слушает localhost и не имеет доступа в систему:
  `ProtectSystem=strict`, пустой `CapabilityBoundingSet`, фильтр системных вызовов.
- Оценку изоляции смотрите сами: `systemd-analyze security monagent.service`.
- Приватные ключи и пароли в репозиторий не кладутся и не выкладываются.
  Служебные учётные записи и токены — только в переменных окружения.
